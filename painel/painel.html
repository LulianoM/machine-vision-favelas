Setup do desktop

Abra este painel no navegador do desktop e copie os blocos na ordem. O roteiro completo, com as explicações, está em docs/SETUP-DESKTOP.md.

1. Instalar o que falta DESKTOP · POWERSHELL 
winget install Git.Git
winget install GitHub.cli
winget install tailscale.tailscale

Depois abra o Tailscale e entre com a conta Google pessoal. No Mac: brew install --cask tailscale e a mesma conta. No painel do Tailscale, renomeie a máquina para desktop e marque "Disable key expiry".

2. Clonar o repositório DESKTOP · POWERSHELL 
gh auth login
mkdir C:\projetos
gh repo clone LulianoM/machine-vision-favelas C:\projetos\machine-vision-favelas

O repositório já existe e é privado: o gh auth login precisa ser feito com a conta LulianoM.

3. Ligar o SSH, só pela rede Tailscale DESKTOP · POWERSHELL ADMIN 
cd C:\projetos\machine-vision-favelas\docs
Set-ExecutionPolicy -Scope Process Bypass -Force
.\setup-desktop.ps1

O script foi escrito no Mac e ainda não foi testado neste Windows. Leia a saída. No fim ele mostra o usuário Windows e o IP Tailscale, que entram no ~/.ssh/config do Mac.

4. Conferir, a partir do Mac MAC · TERMINAL 
ping -c 2 desktop
ssh desktop "nvidia-smi --query-gpu=name,memory.used,memory.total --format=csv"
5. Migrar o trabalho existente DESKTOP · CLAUDE CODE

Abra o Claude Code na pasta antiga de trabalho e cole o conteúdo de docs/PROMPT-MIGRACAO-DESKTOP.md. Ele faz o inventário, copia scripts e métricas para o repositório, deixa datasets e pesos onde estão e atualiza este painel com o estado real do treino.

6. Tela do desktop no Mac AS DUAS

O ARMA 3 precisa de interface gráfica, e SSH não mostra janela. Opção simples: Parsec (host no desktop, cliente no Mac, mesma conta). Opção aberta: Sunshine no desktop e Moonlight no Mac, conectando em desktop pelo Tailscale.
